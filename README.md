# Marathon Event Management System

## About

This project is a Marathon Event Management System. It helps manage marathon events, users, participants, categories, enrolments, and results.

## Features

* Manage users
* Manage user roles
* Create events
* Create categories
* Register participants
* Manage enrolments
* Record event results

## Database Tables

The system contains the following tables:

* Users
* Roles
* UserRoles
* Events
* Categories
* Enrolments
* ParticipantEvents
* Results

## Getting Started

1. Open MySQL Workbench.
2. Create the database.
3. Run the SQL file to create all tables.
4. Connect the database to the application.
5. Run the application.

## Database

```sql
CREATE DATABASE EventManagementDB;

USE EventManagementDB;
```

## Technologies

* C#
* ASP.NET Core
* MySQL
* MySQL Workbench

## Project Purpose

The purpose of this project is to provide a simple system for managing marathon events and participants.
